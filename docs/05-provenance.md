# 来源与公开边界

这是个人演示代码与二次开发快照，运营模块和表单演示合并为一个便于检出的公开仓库。不保留原工作目录Git历史，也不包含实习公司系统源码、legacy/reference目录、私有凭据、企业记录或内部文档。

项目承接的经验是任务失败、重试、业务规则与状态核对的工程问题；不能据此说成在实习公司部署了本仓库完整系统。采购、库存、表单、账号与故障脚本均为合成示例。

Pi SDK 使用npm官方包 `@earendil-works/pi-agent-core`、`@earendil-works/pi-ai`，版本锁定0.85.1；SDK实现归属其原作者。本项目贡献是业务适配、Java约束、场景、测试和可观察轨迹，未将SDK称为自研模型/框架。附带Faux提供器是脚本演示。依赖各自遵循其许可证，本仓库个人代码使用MIT。

旧文件中的W2/W3/W4是开发批次编号，不表示生产上线。冻结评测语料保留用于历史回归，发生冲突以当前业务文档、代码和对应测试为准。
